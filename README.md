# Causeberry

Static redesign for Causeberry, built for GitHub Pages.

The site is self-contained:

- HTML, CSS, and JavaScript are local.
- Original Carrd images are stored in `assets/images`.
- No remote fonts, scripts, or image assets are required to render the page.

## Local Preview

Open `index.html` directly in a browser, or serve the directory with:

```sh
python3 -m http.server 8000
```
